# 🏅 Pontuação dos Atletas

Projeto de certificação em JavaScript que calcula a média válida das notas de atletas em uma competição de ginástica artística.

---

## 📌 Descrição do projeto

Em uma competição de ginástica artística, cada atleta é avaliado por **cinco jurados**, que atribuem notas de **1 a 10**. A regra da competição determina que:

- A **maior** e a **menor** nota devem ser desconsideradas;
- A **média final** deve ser calculada com base nas **três notas restantes**.

Este projeto recebe o nome e as notas de cada atleta, realiza o cálculo corretamente e exibe o resultado no console.

---

## 🧠 O que o projeto faz

Para cada atleta, a aplicação:

1. Ordena as notas em ordem crescente;
2. Remove a menor e a maior nota;
3. Calcula a média das três notas restantes;
4. Exibe no console:

   - Nome do atleta
   - Notas obtidas
   - Média válida

## ▶️ Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/notas-atletas.git
```

2. Acesse a pasta do projeto:

```bash
cd notas-atletas
```

3. Execute o arquivo JavaScript em um ambiente que suporte JS (como o navegador ou o Node.js):

```bash
node notas-atletas.js
```

4. Verifique o resultado no console.
